# ilk-projem

HTML, CSS ve JavaScript ile yazılmış basit bir yapılacaklar listesi.

## Kullanım

`index.html` dosyasını tarayıcıda açman yeterli.

- Görev yazıp **Ekle**'ye bas (ya da Enter'a).
- Kutucuğu işaretleyince görevin üstü çizilir.
- **Sil** ile görevi kaldır.

Görevler tarayıcıda (`localStorage`) saklanır, sayfa yenilense de kaybolmaz.
